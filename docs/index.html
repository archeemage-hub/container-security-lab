Повторить опыт

Настоящий стенд запускается на Linux с Docker и Python. Порядок подготовки, ручные проверки и остановка описаны в гайде. После подготовки базового образа:

python3 scripts/deploy.py
python3 scripts/verify.py

41/41 — число выполненных проверок, а не оценка безопасности в процентах. Эксперимент не включает поиск CVE, атаки на ядро и нагрузочные испытания.

Заметки этой страницы хранятся только в вашем браузере. Отправки на сервер нет.
